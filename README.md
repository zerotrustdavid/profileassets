# profileassets

Supporting assets and tooling for the [zerotrustdavid](https://github.com/zerotrustdavid) GitHub profile.

## Contents

- `assets/` — the light and dark banner SVGs used in the profile README, switched automatically via GitHub's `prefers-color-scheme` markdown trick.
- `.github/workflows/lint.yml` — markdown lint and link-check on every pull request, with third-party actions pinned to a commit SHA rather than a floating tag.
- `SECURITY.md` — the security record for this repo.

Nothing here is required for the profile README to render — it lives in its own repo so [zerotrustdavid/zerotrustdavid](https://github.com/zerotrustdavid/zerotrustdavid) itself stays to a single file.
